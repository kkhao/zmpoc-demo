0. 总览：怎么用这块板子

推荐浏览顺序（与演示板行序一致）： A1 基线 → A1 钻孔柱 → A2 观测更新 → AOI 差值放大 → OpenFDEM 损伤 → 采动反哺示意 → 突水 → 瓦斯 → 融合。

  1. 通用三维操作：在画布上按住拖动可旋转（轨道相机）；底部「播放」自动切帧，「进度条」手动 scrub；「联播轻量行」只播 FDEM/采动反哺/水/气/融合，不联播地质（避免双面卡顿）。
  2. 两类地质更新（必读）：
    • A2 观测更新：新钻孔/掘进揭露 → 数学差值（RBF/AOI），适用于揭露信息修正。局部看不清时用「AOI 差值放大」行。
    • 采动反哺：回采采空区 → 力学损伤/下沉 → 顶板修正示意图层；正式写回 ModelPackage 与三维充填标定仍属规划。
  3. 竖向/差值夸张：钻孔柱 VE 与 AOI「差值夸张」均为显示夸张，角标已标注，非真实比例。
  4. 离屏暂停：滚出可视区后动画会自动停，减轻负载。
  5. 改参重算：仅在本机 serve_demo.py 下可用；GitHub Pages / 纯静态打开时表单会禁用并提示只读。
  6. 演示边界（必读）：地质场景是 USGS PRB Roland/Baker 示范块；材料/地应力为 SCREENING 未现场标定； A 地质 CRS=EPSG:26713 local，突水/瓦斯巷道 CRS=ZM_POC_LOCAL_ENU_v1，采动反哺与 FDEM 同剖面局部系，禁止混空间关联。
  7. 验收主戏：A1/A2 VTK + A3 FDEM 回放 + 采动反哺半闭环示意。

1. A1 基线地质 · VTK 对照

目的

展示 ModelPackage v1 更新前的煤层几何：顶/底板三角网、solid 侧壁、夹矸证据体、断层面、基线钻孔。 用来回答「更新前煤层长什么样」。算法标签：普通克里金（ordinary kriging）。

原理（数据从哪来）

  • 输入：USGS PRB 钻孔约束 → A 侧建 ModelPackage/v1。
  • 网页渲染：直接读 VTK 三角面（roof/floor/solid 侧壁/parting/Fault_1·2），不是示意点云。
  • 帧标量：厚度 thickness_m、顶板高程 roof_elev_m、底板高程 floor_elev_m（共 3 帧）。
  • 琥珀面=夹矸；暗红面=断层；线框=工作面四边。

操作步骤

  1. 在演示板点「从 A1 地质开始」，或滚到 A1 行。
  2. 拖底部进度条：第 1 帧厚度 → 第 2 帧顶板高程（基线面常用）→ 第 3 帧底板高程。
  3. 按住画布拖动旋转，从斜上方看清工作面矩形与钻孔点标注。
  4. 左侧「关键参数」核对：来源 v1、三角面约 1.6 万、钻孔 18、CRS 26713。

读图要点

  • 色条：暖/高 = 当前帧标量更大（厚度更厚或高程更高）。
  • 记住顶板起伏与工作面位置，便于下一步和 A2 对比。

不要误解

A1 没有 AOI/残差帧；也不是中煤现场工作面。

1b. A1 钻孔柱 / 剖面 · 纵向结构

目的

补足全场平面图对钻孔纵向结构与夹矸埋藏关系的表达不足。

操作

  1. 切换竖向放大 ×1 / ×10 / ×20（角标会标注「非真实比例」）。
  2. 拖进度条切换选中孔；高亮柱段：灰=覆岩、黑=煤、琥珀=夹矸。
  3. 点击标记点读「孔口 / 煤层顶界 / 夹矸 / 底板」高程。
  4. 折线为过选中孔的顶底板剖切采样。

边界

示意岩性柱，非全井地层库；夹矸为 catalog 局部证据体，不作全区连续层。

2. A2 观测更新 · 新孔/揭露差值（非采动演化）

目的

展示 ModelPackage v2「观测约束更新」：在同拓扑上用新钻孔/掘进揭露做 AOI 局部 RBF 残差修正。 适用于掘进揭露信息修正；不承担回采采空区断裂/垮落/充填的物理演化。

原理

  • 几何仍是 VTK 直面；帧含 aoi_weight、v1_to_v2_roof_dz 等。
  • 更新驱动：新孔约束 + 数学差值，不是 OpenFDEM 力学结果。
  • 采空区顶板垮落形态请看 采动反哺示意。

操作步骤

  1. A1 停在 roof_elev_m 记住形态。
  2. 本行拖到 aoi_weight / v1_to_v2_roof_dz 看观测更新区。

边界

CRS=EPSG:26713 local。与采动反哺、水/瓦斯巷道勿混谈同框。

4. 采动反哺示意 · 六步闭环（岩体状态 / 充填 / 同化）

目的

回应「损伤×下沉不能只停在表面高程」：扩展到岩体状态、自然垮落/人工充填双路径、监测残差示意同化与下一阶段外推。

六步闭环

  1. 现场观测（示范矿压点）
  2. 更新模型与参数（sag_fraction 等示意）
  3. 采动力学计算（OpenFDEM 历史损伤）
  4. 更新采后结构（roof_dz / 离层 / 收敛 / 支架代理）
  5. 与新监测比较（观测−计算残差）
  6. 下一阶段预测（规则外推帧）

操作

  1. 播放帧：roof_dz → bed_separation / convergence / support_proxy → goaf_natural / goaf_backfill → forecast_*。
  2. 切换「自然垮落 / 人工充填」：接顶率×龄期×承载折减有效下沉（示意）。

边界

screening；非 OpenFDEM 充填本构；不自动写回 ModelPackage。真标定属二期。

8. 常见问题

  • A2 和采动反哺有何不同？A2=观测差值（掘进/新孔）；采动反哺=力学损伤→顶板修正示意（回采）。
  • 为什么全场 A1/A2 几乎一样？2 km 尺度压缩局部数米；请看「AOI 差值放大」行（真实米制 Δz）。
  • 竖向放大是真厚度吗？不是。×10/×20 仅显示夸张，角标有说明。
  • 采动反哺是否已写回地质包？POC 半闭环仅出示意图层，未写回 ModelPackage。
  • 为什么看不到电影级垮塌？破缝+下沉+roof_dz 示意；完整块体请 ParaView。
  • 改参按钮灰了？静态 Pages 或未启动 serve_demo。
