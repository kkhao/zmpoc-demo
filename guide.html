0. 总览：怎么用这块板子

推荐浏览顺序（与演示板行序一致）： A1 基线地质 → A2 更新地质 → OpenFDEM 损伤/垮塌 → 突水 → 瓦斯 → 多源融合。

  1. 通用三维操作：在画布上按住拖动可旋转（轨道相机）；底部「播放」自动切帧，「进度条」手动 scrub；「联播轻量行」只播 FDEM/水/气/融合，不联播地质（避免双面卡顿）。
  2. 离屏暂停：滚出可视区后动画会自动停，减轻负载。
  3. 改参重算：仅在本机 serve_demo.py 下可用；GitHub Pages / 纯静态打开时表单会禁用并提示只读。
  4. 演示边界（必读）：地质场景是 USGS PRB Roland/Baker 示范块；材料/地应力为 SCREENING 未现场标定； A 地质 CRS=EPSG:26713 local，突水/瓦斯巷道 CRS=ZM_POC_LOCAL_ENU_v1，禁止混空间关联。
  5. 验收主戏：A1/A2 VTK 直面 + A3 Linux 真算 FDEM（含 CZM 破缝与顶板下沉示意）。

1. A1 基线地质 · VTK 对照

目的

展示 ModelPackage v1 更新前的煤层几何：顶/底板三角网、solid 侧壁、夹矸证据体、断层面、基线钻孔。 用来回答「更新前煤层长什么样」。算法标签：普通克里金（ordinary kriging）。

原理（数据从哪来）

  • 输入：USGS PRB 钻孔约束 → A 侧建 ModelPackage/v1。
  • 网页渲染：直接读 VTK 三角面（roof/floor/solid 侧壁/parting/Fault_1·2），不是示意点云。
  • 帧标量：厚度 thickness_m、顶板高程 roof_elev_m、底板高程 floor_elev_m（共 3 帧）。
  • 琥珀面=夹矸；暗红面=断层；线框=工作面四边。

操作步骤

  1. 在演示板点「从 A1 地质开始」，或滚到 A1 行。
  2. 拖底部进度条：第 1 帧厚度 → 第 2 帧顶板高程（基线面常用）→ 第 3 帧底板高程。
  3. 按住画布拖动旋转，从斜上方看清工作面矩形与钻孔点标注。
  4. 左侧「关键参数」核对：来源 v1、三角面约 1.6 万、钻孔 18、CRS 26713。

读图要点

  • 色条：暖/高 = 当前帧标量更大（厚度更厚或高程更高）。
  • 记住顶板起伏与工作面位置，便于下一步和 A2 对比。

不要误解

A1 没有 AOI/残差帧；也不是中煤现场工作面。

2. A2 地质对照 · VTK 顶底板/侧壁/夹矸/断层

目的

展示 ModelPackage v2：在同拓扑上做 AOI 局部 RBF 残差更新（新孔约束）， 用来回答「相对 A1，哪里改了、改了多少」。算法标签：kriging + RBF AOI。

原理

  • 几何仍是 VTK 直面（顶/底/侧壁/夹矸/断层）；夹矸与新孔比 A1 更多。
  • 帧标量（6 帧）： thickness_m → aoi_weight → roof_delta_m → floor_delta_m → roof_elev_m → v1_to_v2_roof_dz。
  • aoi_weight：更新区权重（高值≈本次残差更新作用区）。
  • v1_to_v2_roof_dz：相对 A1 的顶板高程差，对比更新幅度最直观。
  • 线框含工作面边界 + A2 AOI 盒。

操作步骤（推荐对比流程）

  1. 先在 A1 停在 roof_elev_m，心里记住形态。
  2. 滚到 A2 行，拖进度条到 aoi_weight：看高值落在哪一片。
  3. 再拖到 v1_to_v2_roof_dz：高/低差对应「抬升/压低」幅度。
  4. 可选扫 roof_delta_m / floor_delta_m 看残差场。
  5. 旋转到与 A1 相近视角，上下对照口述「更新区」。

读图要点

  • AOI 高值区应与 Δz / 残差明显区域大致重合。
  • 参数区：钻孔约 22（基线+新孔）、夹矸更多、帧数 6。

边界

CRS 仍为 EPSG:26713 local；勿与下方突水/瓦斯示范巷道混谈空间关系。

3. OpenFDEM 损伤演化 · 3D（含垮塌示意）

目的

展示 A3 FdemMeshPackage 经 Linux OpenFDEM 8 步开挖真算后的损伤演化， 并用 CZM 破缝 + 顶板下沉把「垮塌机理」做成可见效果（非预画碎块动画）。

原理

  • 主路径：2D 平面应变长壁剖面 → 场 VTU（damage）→ 沿走向挤成薄板点云便于旋转。
  • 深红短线：从 cohesive_elements_*.vtp 提取 damageValue≥0.5 的破缝边。
  • 顶板大红点下沉：煤层顶以上、高损伤点随开挖进程按损伤加权下移（示意垮塌，非刚体动力学）。
  • 左下角 CZM 破缝 N：当前帧破缝单元数（随播放递增，末态约三百量级；报告统计 final_broken_czm≈465）。
  • 灰线框：顶/煤/底分层 + A2 剖面叠层（mesh2d 局部坐标）。
  • 材料：SCREENING_ONLY，未现场标定。

操作步骤

  1. 打开演示板 FDEM 行（或点顶部「OpenFDEM 主戏」）。
  2. 点「播放」，或把进度条从最左拖到最右。
  3. 观察：损伤由冷到暖；深红破缝变密；顶板点明显下沉；左下角计数上升。
  4. 左侧关键参数核对：开挖步数 8、CZM 破裂、场 VTU→板子帧数、材料 screening。
  5. 右侧：周期来压示意曲线（若有）；场景下拉可改（本机 API 下重建可视化）。

改参说明（易误解点）

按钮文案为「重建可视化（历史结果回放）」：默认不重新跑 OpenFDEM 求解，只按参数重映已有 VTU。 真·重算需本机正式 OpenFDEM 作业链（run_a3_staged_excavation.py）。

读图要点

  • 要讲垮塌：盯破缝 + 顶板下沉 + CZM 计数，而不是期待「石块掉落」电影级动画。
  • ParaView 可打开 result_staged_excavation/ 查看完整 VTU/VTP。

4. 突水蔓延

目的

演示矿方示范巷道网上的突水/积水三维蔓延能力（FV3D 体素守恒或网络降阶）， 不是 Roland 工作面地质同框。

原理

  • 巷道体素上做含水比例 α 的输运：邻体交换、走廊混合、重力偏置（水倾向低洼）。
  • 源点通常为低洼积水节点（如 N7）；色深 = α 高。
  • CRS：ZM_POC_LOCAL_ENU_v1。

操作步骤

  1. 点「播放」或拖进度条，看含水团从源点向连通巷道推进。
  2. 左侧可改注入强度、步数、重力偏置、精度（需本机 API）。
  3. 右侧「当前帧读数」随进度刷新节点水位摘要。

边界

与 A1/A2 VTK 不同 CRS；讲解时明确「监测侧能力展示」。Pages 上改参不可用。

5. 瓦斯蔓延

目的

演示示范巷道内瓦斯涌出后的对流–扩散浓度场，帮助理解风流携带与联巷扩展。

原理

  • 体素上对流–扩散：进风→回风指示风速 + 扩散 + 弱衰减。
  • 源点多为工作面节点（如 N4）；暖色 = 浓度高。
  • CRS 同突水：ZM_POC_LOCAL_ENU_v1。

操作步骤

  1. 播放整段时序，观察浓度沿运顺/轨顺与联巷扩展。
  2. 本机可下调涌出强度、扩散、通风指示风速等后重算。
  3. 对照进风/回风口理解「风流携带」叙事。

边界

浓度多为演示量纲；通风非现场标定。勿与 A 地质 VTK 叠图。

6. 多源融合 · 应力/渗流属性场

目的

在同一几何上承载应力/矿压/渗流/瓦斯等多参数属性，叠加构造线框与超阈异常点， 并给出 ahead_geology 类前方条带评分（POC 级）。

原理

  • 监测台账 → Envelope → IDW 属性场 → 脉冲时序体场。
  • 异常事件与构造折线缓冲带做空间关联。
  • ahead_geology：超前条带趋势 + 缓冲带异常融合评分，不是 A2 VTK 地质预报。

操作步骤

  1. 用图层下拉切换 stress / seepage / mine_pressure / gas。
  2. 播放看脉冲时序；注意线框=构造、圆点=异常。
  3. 本机可改脉冲倍率、帧数、展望时长后「改参融合」。

读图与边界

勿把融合层说成「已与 A2 煤层同 CRS 同化」。现场数据替换后需统一 crs_id 再谈同框。

7. 常见问题

  • 为什么看不到电影级垮塌？网页用破缝线 + 顶板下沉示意 CZM 机理；完整碎块过程请用 ParaView 打开 cohesive/field 结果。
  • A1/A2 看起来差不多？几何同拓扑；请把 A2 拖到 aoi_weight / v1_to_v2_roof_dz 才能看出更新区。
  • 改参按钮灰了？当前是静态 Pages 或未启动 serve_demo.py。
  • 全部自动播放卡顿？请用「联播轻量行」，地质请单独播放。
  • 突水/瓦斯和地质对不上？两套 CRS，属故意分离的对照演示。
  • 数字 465 和左下角破缝数不一致？报告为全量 broken 统计；网页为抽样破缝边（有上限）+ 阈值≥0.5，量级同趋势即可。
